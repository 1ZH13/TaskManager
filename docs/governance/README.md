# Gobierno técnico — Epic E0

Este directorio contiene las decisiones transversales aprobadas antes de iniciar el desarrollo del frontend de TaskManager. Es la fuente de trazabilidad para el Epic E0 del backlog y complementa el [PRD](../../PRD.md) y el [plan de implementación](../../IMPLEMENTATION_PLAN.md).

## Entregables

| Entregable | Issue hijo | Propósito |
| --- | --- | --- |
| [Decisiones de arquitectura](architecture-decisions.md) | E0-I1 | Fijar las decisiones que evitan cambios estructurales posteriores. |
| [Autorización de demostración](authorization.md) | E0-I2 | Especificar capacidades por rol y el contrato puro de autorización. |
| [Calidad y definición de terminado](quality-strategy.md) | E0-I3 | Establecer controles, tipos de prueba y evidencia de cierre. |

## Estado

Los tres entregables del Epic E0 están documentados. Las decisiones marcadas como pendientes no bloquean el inicio del frontend; las que sí condicionan una integración real están identificadas explícitamente para resolverse antes del backend.
